# 부기 메타버스 (Bookie)

초등학생이 동화책 속으로 들어가 이야기를 만나고, 세계를 직접 만들어 블록·자바스크립트로 움직이는 교육용 웹앱.

- 동화책: `worlds/rabbit-turtle/` (토끼와 거북이)
- 세계 만들기: `maker.html` (꾸미기 · 블록 · 코드 · 도트 공방)
- 아바타·기록장: `avatar-maker.html`

학생 기록장과 만든 세계는 사용자 컴퓨터에만 저장되며, 이 사이트는 개인정보를 수집하지 않습니다.
포함된 라이브러리: three.js(MIT), Blockly(Apache-2.0), acorn·astring·CodeMirror(MIT).

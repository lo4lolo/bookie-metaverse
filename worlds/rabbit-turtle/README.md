# 동화책 세계 1 · 토끼와 거북이

학생이 펼친 동화책 속으로 들어가 토끼·거북이·부엉이 심판을 만나는 3D 이야기 공간. 대상 초등 1~2학년, 한 번 읽는 데 10~15분.

주소: 서버를 켠 뒤 `http://<선생님 PC>:8838/worlds/rabbit-turtle/` (로그인 화면 아래 "🐢 동화책" 링크).
> `file://`로 열면 안 된다(브라우저가 모듈·그림을 막음). 서버 없이 쓰려면 `public` 폴더에서 `python -m http.server`.

## 이야기(7쪽)

1. **책 속으로** — "펑!" 책에 들어옴 → 부엉이 심판에게 걸어가기(땅 누르기 연습).
2. **놀리는 토끼** — 토끼가 거북이를 놀림 → *거북이 마음은?* → *거북이에게 해 줄 말 고르기* → 거북이가 시합 제안.
3. **출발선** — 출발선으로 이동 → 학생이 🚩 출발 신호 → 셋·둘·하나·출발!
4. **깡충깡충, 엉금엉금** — 토끼는 빨리, 거북이는 천천히 → 큰 사과나무까지 따라가기 → 토끼 낮잠 → *토끼는 왜 잤을까?* → 깨워 볼까?
5. **개울 건너기** — 거북이에게 돌아가기 → **징검돌 1~5번 차례로 누르기**(하나·둘·셋… 세기) → *거북이는 어떻게 가나요?*
6. **결승선** — 거북이를 응원하며 결승선까지 → 토끼가 깨어 달리지만 거북이 승리 → 꽃가루.
7. **이야기가 남긴 마음** — 토끼의 사과, 거북이의 용서 → *무엇을 배웠나요?* → **나의 다짐**(책 읽기·글씨 쓰기·줄넘기·정리 정돈) → 선물.

글쓰기 원칙: 한 문장 25자 안팎, 쉬운 낱말, "~해요"체, 틀린 답에도 꾸짖지 않고 "음… ~해 볼까요?"로 다시 생각하게. 모든 대답은 기록장에 그대로 남는다(정답 채점 없음).

## 조작

- 걷기: 땅 누르기 / W A S D / 화살표 · 화면 돌리기: Q E, ⟲ ⟳, 끌기(놓으면 45° 칸에 맞춤) · 확대: 휠
- 대화: 다음 ▶ / 스페이스 / Enter · 고르기: 누르기 / 숫자 1~4
- 🔊 읽어 주기(브라우저 한국어 음성, 인물마다 목소리 높낮이 다름) — 끄기 가능
- 진행은 쪽마다 브라우저에 저장 → 새로고침해도 "이어서 읽기"

## 기록장

끝 화면 "📒 기록장에 저장하기" → `석산기록장_<이름>.md` 내려받기. 손님은 이름만 쓰면 새 기록장이 만들어진다.
저장되는 것: 대답 5개, 다짐, 꾸준함의 돌, 거북이 등딱지 스티커, 포인트 10(**보류**). 형식은 `38_석산메타버스/학생md_형식.md`.

## 그림 방향(지킬 것)

- **배경**: 동화책 3D — 종이 질감, 부드러운 수채화, 둥근 장난감 모양, 진한 갈색 테두리(`INK #4a3426`), 따뜻한 빛. 실사·어두운 색 금지.
- **인물**: 픽셀엔진 도트(64px, 리틀테일풍, 얼굴·몸 좌우 대칭, 머리 모양만 예외). 3D에서는 흰 스티커 테두리 + 둥근 그림자.
- 승인 v5는 다시 그리지 않는다. 학생 색은 `roles.json` 역할 지도로만 바꾼다.
